# Hermes 待办桌宠侧边栏

这是一个 Windows 桌面待办原型。闲置时，它像桌宠一样停在桌面右下角；点击桌宠入口后，会从右侧展开 360px 的待办面板，用来查看、添加和完成待办事项。

## 当前能完成的功能

- 桌宠式闲置入口：收起后显示 `88px x 96px` 的悬浮入口，不再占用全高侧边栏。
- 点击展开待办面板：从右侧覆盖展开，不推开其他窗口。
- 顶部主导航：展开后分为 `今日待办` 和 `周期计划` 两个入口。
- 今日待办：合并手动待办和今天日期命中的周期计划条目。
- 周期计划：展示健身计划、教程学习计划、日期条目和统一 JSON/Markdown 内容块。
- 待办本地操作：支持新增、完成、筛选、来源标签和同步状态标签。
- 本地持久化：新增、完成后的待办会写入 `localStorage`，刷新或重开前端预览后可恢复。
- 周期计划持久化：周期计划条目的完成状态会写入 `localStorage`。
- 扩展骨架：已为 Hermes/飞书同步、系统提醒、桌宠位置记忆分别建立独立模块。

## 仍未完成的能力

- 还没有真实 Hermes 云端同步。
- 还没有真实飞书机器人或多维表格写入。
- 还没有启用提醒时间、稍后和 Windows 系统级通知弹窗。
- 还没有桌宠拖拽、贴边吸附、开机自启动、托盘菜单等完整桌宠能力。
- 周期计划目前仍是本地 demo，不会调用真实 AI，也不会从 Hermes 拉取计划。

这些能力的扩展入口见 [docs/extension-points.md](docs/extension-points.md)。

## 常用命令

```powershell
npm install
npm test
npm run typecheck
npm run build
npm start
npm run dev
```

`npm run dev` 默认启动前端预览：`http://127.0.0.1:5173`。如果需要指定端口，可以使用 Vite 参数，例如：

```powershell
npm run dev -- --port 5178
```

`npm start` 会启动已构建的 Electron 桌面壳，请先运行 `npm run build`。

## 文件管理原则

- 不把全部 UI 写进 `App.tsx`。
- 单个组件文件目标不超过 220 行；超过时拆成视图、逻辑、类型和样式文件。
- Hermes、飞书、提醒、桌宠位置等能力都通过独立模块接入，不直接写进 UI 组件。
