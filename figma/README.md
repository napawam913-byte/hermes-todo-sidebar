## 当前版本

当前 Figma 已清理为一个主版本，只保留可拖动桌宠与锚定下拉面板方案。

核心结构：

- 收起状态显示 `88px x 96px` 桌宠，可在主屏和副屏自由拖动。
- 点击桌宠后显示 `360px` 宽、目标 `560px` 高的锚定面板。
- 桌宠在上方时面板向下展开；靠近底部时面板向上展开。
- 空间不足时缩短面板高度，内容区域内部滚动，桌宠位置不跳动。
- 顶部导航保留 `今日待办 / 周期计划`，详情在同一面板内切页。

## 交互规则

1. 按下并移动不超过 `5px` 视为点击，展开面板。
2. 移动超过 `5px` 进入拖动，不触发展开。
3. 松手后将桌宠限制在当前显示器工作区，并永久保存位置。
4. 展开方向选择上下可用空间更大的一侧；相同则向下。
5. 展开状态禁止拖动，点击桌宠或窗口失焦后收起。
6. 点击待办或周期计划后，在原面板内切换到详情页。

## 实现提醒

- Electron 拖动、双屏几何和位置持久化统一放在 `src/main/pet/`。
- renderer 只处理拖动手势和视图状态，不直接操作 `BrowserWindow`。
- 待办和周期计划模块不得读取 Electron 坐标。
- Figma 使用 `Noto Sans SC`；生产端继续使用 Windows 系统字体栈。
- 代码阶段必须继续满足单个 TS、TSX、CSS 文件不超过 `220` 行。
