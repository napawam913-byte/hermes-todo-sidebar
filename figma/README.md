## 当前视觉基准

当前唯一界面基准为 `Neutral Glass / 中性玻璃`。角色只提供动作图集，不再改变面板、卡片、按钮、文字或状态颜色。

- 面板：中性冷白，默认不透明度 `86%`，可调范围 `72%–94%`。
- 主操作色：固定 `#007AFF`。
- 正文：`#1D1D1F`；高不透明卡片次级文字：`#6E6E73`。
- 直接位于透明面板上的小字：`#3A3A3C`，保证最低透明度下的对比度。
- 卡片：`rgba(255,255,255,0.92)`。
- 控件底色：`rgba(118,118,128,0.12)`。
- 分割线：`rgba(60,60,67,0.16)`。
- 面板圆角 `12px`；卡片和控件圆角 `8px`。
- Figma 使用 `Noto Sans SC`；运行时使用 Windows 系统字体栈。

不同角色包只能改变桌宠图像，不能提供或注入 UI 主题色。新增角色时只需制作标准状态图集与 Manifest。

## 响应式规则

1. 面板宽度不足 `720px` 时采用单页布局，详情在同一面板切页并显示返回按钮。
2. 面板宽度达到 `720px` 且选中条目时，采用约 `40% / 60%` 的列表与详情布局。
3. 宽屏默认页主要内容最大宽度约 `760px`，不会把卡片无限横向拉伸。
4. 列表、详情和 AI 对话各自在自己的内容区滚动，不能把底部操作区推出窗口。
5. `360px` 紧凑状态不得出现横向滚动、文字溢出或按钮重叠。

## 角色与界面边界

- `CharacterPack v2` 只包含角色身份、图集和动作片段。
- 旧 `CharacterPack v1` 通过适配器读取，`theme` 字段会被丢弃。
- 外观设置只保存 `panelOpacity` 与 `characterId`。
- 找不到已选角色时回退到默认企鹅，不影响应用启动。
- 角色切换不改变 `#007AFF`、语义红色、成功绿色和中性材质。

## 保留功能

- 桌宠点击与拖动阈值、双屏边界、锚定展开和位置持久化保持不变。
- 顶部导航继续使用 `今日待办 / 周期任务`。
- 今日待办、周期计划、详情和 AI 工作流继续复用同一面板。
- AI 仍执行 `对话 → 提案 → 人工确认 → 原子写入`，不会直接修改数据。
- AI 长对话、提案和设置页面后续统一换用同一套 Neutral Glass Token。

## 实现约束

- 不新增视觉 UI 框架或全局状态库。
- 所有 TS、TSX、CSS 文件不超过 `220` 行。
- 运行时代码以本文件和 `nodes.json` 中的最新节点为唯一视觉依据。
- 当前稳定/测试副本不得被覆盖；本轮最终测试副本为 `0.1.3-test.13`。
