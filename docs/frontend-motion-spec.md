# 前端动效规格

## Neutral Glass 与状态反馈

- Neutral Glass 的模糊、透明度和阴影只用于表达面板层级，不以角色主题色驱动；切换角色不会触发整套界面换色或布局动画。
- 外观设置中的透明度调整在 `120ms` 内平滑过渡，范围固定为 `72%` 到 `94%`，默认 `86%`。减少动效模式下保留颜色与透明度变化，不使用位移或缩放。
- 详情页面进入采用 `180ms` 的信息层级切换；在窄面板中仍为单页前进/返回，不扩展为第二个抽屉。
- AI 对话区、消息列表和输入区保持独立滚动关系：消息增长只滚动消息区，底部 composer 固定可见；生成中只显示状态反馈，不推挤输入区。
- AI 提案与执行结果的新增、修改、完成、警告和删除分别使用 `--ui-accent`、`--ui-success`、`--ui-warning`、`--ui-danger`。小字号状态文案使用对应的 `*-text` 高对比前景色；柔和状态底色使用对应语义色的约 `12%` 透明混合，不播放抖动或持续闪烁。
- 同步、提醒和状态菜单的文案、边框、背景变化持续 `120ms`；失败态使用危险色边框和文字，成功态使用成功色，不改变菜单尺寸或列表位置。
- 响应式断点为 `720px`：宽面板维持主从信息结构，窄面板改为同面板切页；两种布局切换均不新增角色相关的颜色或特效。


本文档描述 Hermes 可拖动待办桌宠第一阶段前端动效。所有动效只服务于状态变化，不做装饰性编排。

## 全局规则

- 侧边栏缓动：`cubic-bezier(0.2, 0.8, 0.2, 1)`。
- 大多数反馈控制在 `80ms` 到 `220ms`。
- 所有位移和缩放都必须尊重 `prefers-reduced-motion`。
- 减少动态效果模式下关闭位移和缩放，只保留透明度、颜色、边框变化。

## 桌宠式闲置入口

- 尺寸：`88px x 96px`。
- 初始位置：主屏工作区右下方，距离右侧和底部各 `24px`。
- 自由拖动：按下后 X 或 Y 达到 `4px` 才进入拖动；窗口直接跟随系统鼠标坐标，不添加延迟缓动。
- 四向步态：向下使用正面、向上使用背面、向右使用侧面；向左只镜像侧面角色图层。
- 方向更新：累计移动至少 `3px` 后判断，新轴需达到旧轴的 `1.25` 倍才切换，避免斜向闪烁。
- 移动暂停：指针停止超过 `120ms` 时停在当前行走帧，继续移动后恢复；松开后回到闲置。
- 松手：把桌宠完整限制在当前显示器工作区内，并保存 `pet-position.v1.json`。
- 显示器变化：副屏断开或分辨率改变后校正到可见工作区，不播放跨屏飞行动效。
- hover：桌宠主体轻微上浮 `-2px`，背景和边框颜色过渡 `120ms`。
- press：缩放到 `0.98`，持续 `80ms`，松开后 `120ms` 回到正常。
- 待办数量 badge 固定在桌宠右下角。
- 第一版不展示已到点红点；后续启用真实提醒时再补状态变化动效。
- 减少动态效果模式关闭迈步动画，但保留上、下、左、右对应的静态朝向。

## 锚定展开与收起

- 面板宽度约为所在显示器工作区的 `50%`，限制在 `360px–960px`；目标高度约为工作区的 `57%`，限制在 `420px–720px`，与桌宠间距 `8px`。
- 展开方向：选择桌宠上下可用空间更大的一侧；空间相同默认向下。
- 向下出现：透明度 `0 -> 1`，Y 位移 `-6px -> 0`，持续 `220ms`。
- 向上出现：透明度 `0 -> 1`，Y 位移 `6px -> 0`，持续 `220ms`。
- 空间不足：缩短面板实际高度，列表和详情正文内部滚动。
- 收起：面板淡出，原桌宠锚点保持不跳动，持续 `180ms`。
- 展开态覆盖当前桌面内容，不推开其他窗口。
- 失焦自动收起和手动收起使用同一套收起动效。

## 同面板详情

- 点击待办、周期计划或编辑入口时继续使用同一 DOM 主从结构；窄面板内切页，宽度达到 `720px` 时保留列表并以 `40% / 60%` 展示详情。
- 详情进入：透明度 `0 -> 1`，X 位移 `10px -> 0`，持续 `180ms`。
- 窄面板返回列表使用相反的信息层级切换；宽面板关闭详情后回到最大 `760px` 的居中列表，不创建第二套抽屉 DOM。
- `prefers-reduced-motion` 下取消 X 位移，仅保留透明度变化。

## 后续菜单扩展

- 第一版不展示稍后菜单。
- 后续菜单出现：透明度 `0 -> 1`，Y 位移 `-6px -> 0`，持续 `140ms`。
- 菜单使用固定定位，避免被待办列表滚动容器裁剪。

## 按钮反馈

- hover：背景色、边框和图标颜色过渡 `120ms`。
- press：缩放 `0.98`，持续 `80ms`。
- release：`120ms` 回到正常状态。
- 按钮文字在 hover 和 press 时不能换行、跳动或改变尺寸。

## 待办条目

- 完成待办：条目透明度降到 `0.62`，持续 `180ms`。
- 列表重排：持续 `160ms`。
- 第一版不展示已到点提醒；后续启用提醒时，左侧状态条可闪烁一次，持续 `480ms`，随后回到稳定状态。

## 同步状态

- 同步标签文案、边框和背景变化持续 `120ms`。
- 同步失败使用红色边框和红色文字。
- 同步失败不抖动、不弹跳、不移动待办条目。

## 减少动态效果

CSS 验收规则：

```css
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    transition-property: background-color, border-color, color, opacity !important;
    transform: none !important;
  }
}
```

对应 TypeScript token 位于 `apps/desktop/src/renderer/styles/motionTokens.ts`。
