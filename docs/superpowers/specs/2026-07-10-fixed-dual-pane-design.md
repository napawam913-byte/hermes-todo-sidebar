# 固定双栏详情面板设计

## 目标

周期任务详情打开后，左侧主面板保持 `360px`，右侧详情面板独立占用 `400px`。顶部主导航、标题和计划列表不随详情面板伸长。

## 布局

- 默认展开态：只显示 `360px` 主面板。
- 详情展开态：容器总宽度为 `760px`，由 `360px` 主面板和 `400px` 详情面板组成。
- `.sidebar-content` 和 `.todo-panel` 明确固定为 `360px`。
- 右侧详情从 `left: 360px` 开始，不保留旧版 `24px` 灰色遮罩带。
- 左侧计划列表保持可见，选中计划用浅青色背景和完整焦点轮廓表达状态。

## 详情层级

- 顶部：固定标题栏，包含“周期任务详情”、计划名和关闭按钮。
- 摘要：显示计划周期、生成规则和今日命中数量。
- 条目：按日期排列，选中条目使用完整边框和浅色背景，不使用左侧彩条。
- 内容：展示当前条目的统一 `contentBlocks`，健身内容继续使用专用回显。
- 滚动：详情面板独立纵向滚动，标题栏保持在顶部。

## Electron 窗口联动

- 普通展开态的原生窗口宽度保持 `360px`。
- 详情打开态的原生窗口扩为 `760px`，并继续贴在工作区右侧。
- `CyclePlanView` 只上报 `detailOpen`，不直接调用 Electron。
- `SidebarShell` 通过 preload 安全桥接状态，主进程统一计算 BrowserWindow bounds。
- 窗口收起时清除详情状态，避免下次展开直接恢复宽窗口。

## 视觉与动效

- 延续现有青绿色强调色和 4px 间距体系。
- 双栏之间只使用 `1px` 分隔线和轻量阴影。
- 详情面板以 `220ms` 从右侧淡入，不移动左侧主面板。
- `prefers-reduced-motion` 下取消位移，只保留即时状态变化。
- 所有计划卡、日期条目和顶部 tab 使用统一青绿色 `focus-visible` 轮廓。

## 验收

- 打开健身计划后，`.todo-panel` 和顶部 tab 的宽度与打开前一致。
- 页面中不存在 24px 灰色夹层。
- 右侧详情宽度为 `400px`，标题固定，正文可滚动。
- Electron 详情模式窗口为 `760px`，关闭详情后恢复 `360px`。
- 左侧计划卡仍可切换，关闭按钮可回到单栏状态。
- `npm test`、`npm run typecheck` 和 `npm run build` 通过。
