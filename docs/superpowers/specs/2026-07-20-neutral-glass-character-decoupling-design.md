# 桌宠中性玻璃界面与角色解耦设计规范

- 日期：2026-07-20
- 状态：已确认设计，待实施计划
- 适用项目：Hermes Todo Sidebar Windows 桌宠

## 1. 背景与问题

当前横向和纵向面板虽然复用了大部分组件，但最终颜色并不稳定，原因包括：

1. `CharacterPackManifestV1.theme` 会把角色的强调色和底色注入整个应用界面。
2. 面板默认透明度较低，桌面壁纸会参与混色；白色窗口、蓝灰壁纸和深色壁纸下观感差异明显。
3. 部分组件直接使用角色强调色，角色美术与业务界面形成了不必要的耦合。
4. 宽面板会横向拉伸控件，窄面板又采用不同密度，进一步放大了视觉差异。

本次统一使用 `Neutral Glass / 中性玻璃` 风格：借鉴 Apple 界面的克制层级与轻量材质，同时保留 Windows 桌面应用所需的可读性和响应式能力。

## 2. 目标

- 横向、纵向、详情、设置和 AI 页面共用同一套颜色与材质 Token。
- 更换桌宠角色时只更换动作资源，不改变应用界面颜色。
- 桌面背景仍可隐约透出，但不能明显改变界面的综合色相。
- 宽面板有效利用空间，窄面板不出现横向滚动或文字遮挡。
- 保持现有待办、周期计划、AI 提案和桌宠拖动的数据与交互合同不变。
- 所有新增或拆分的 TS、TSX、CSS 文件继续不超过 220 行。

## 3. 非目标

- 第一版不增加深色主题或跟随系统主题。
- 不允许角色包定义按钮、卡片、文字或面板颜色。
- 不改变待办、周期计划、AI 提案和本地持久化的数据结构。
- 不重新设计桌宠动作图集协议中的状态和帧数。
- 不在本阶段新增 Hermes、飞书、提醒或服务器能力。

## 4. 视觉基础

### 4.1 固定配色

应用使用全局固定的中性配色，不从角色包读取颜色：

| Token | 建议值 | 用途 |
| --- | --- | --- |
| `--ui-panel` | `rgba(246, 247, 249, 0.86)` | 最外层磨砂面板 |
| `--ui-surface` | `rgba(255, 255, 255, 0.92)` | 卡片和内容表面 |
| `--ui-control` | `rgba(118, 118, 128, 0.12)` | 分段控件和次级按钮底色 |
| `--ui-border` | `rgba(60, 60, 67, 0.16)` | 细边框与分隔线 |
| `--ui-text` | `#1D1D1F` | 主文字 |
| `--ui-text-secondary` | `#6E6E73` | 次级说明 |
| `--ui-text-tertiary` | `#8E8E93` | 弱提示与占位文字 |
| `--ui-accent` | `#007AFF` | 主操作、选中和焦点 |
| `--ui-accent-hover` | `#0066D6` | 主操作悬停 |
| `--ui-accent-soft` | `rgba(0, 122, 255, 0.12)` | 轻量选中背景 |
| `--ui-success` | `#248A3D` | 成功状态 |
| `--ui-danger` | `#D70015` | 删除和错误 |
| `--ui-warning` | `#B25000` | 警告状态 |

蓝色只用于明确的交互和焦点，不用于大面积装饰。成功、警告和危险色只表达对应语义。

### 4.2 材质与透明度

- 新安装默认面板透明度为 `86%`，用户可在 `72%` 至 `94%` 之间调整。
- 透明度滑块只改变中性面板的 Alpha，不允许切换色相或角色底色。
- 卡片有效不透明度至少比外层面板高 6 个百分点，保证文本区域稳定可读。
- 面板使用 `backdrop-filter: blur(28px) saturate(1.08)`。
- 面板圆角为 `12px`，卡片、输入框和分段控件圆角不超过 `8px`。
- 面板阴影为 `0 18px 48px rgba(0, 0, 0, 0.14)`，卡片默认不使用明显悬浮阴影。
- `prefers-reduced-transparency` 下关闭模糊并将面板不透明度提升至 `96%`。

### 4.3 字体与密度

- Windows 使用 `Segoe UI Variable`，后备为系统无衬线字体。
- 字号不随视口宽度缩放，字距固定为 `0`。
- 页面标题建议 `20px`，区块标题 `15px`，正文 `13px` 至 `14px`，辅助文字 `12px`。
- 图标按钮保持稳定的 `32px × 32px`，常规控件高度为 `36px` 至 `40px`。

## 5. 响应式布局

布局根据面板容器宽度判断，不使用整个显示器宽度作为 CSS 断点：

- 小于 `480px`：紧凑单页模式，详情替换列表并显示返回按钮。
- `480px` 至 `719px`：标准单列模式，内容宽度填满面板但保留稳定边距。
- 大于等于 `720px`：默认页仍为整洁单列；选中条目后切换为 `40%` 列表和 `60%` 详情。
- 宽屏默认页的主要内容最大宽度为 `760px` 并居中，避免输入框和卡片无限拉长。
- 主从布局两栏分别滚动，中间使用一条 Hairline 分隔线，不嵌套装饰性卡片。
- 横向和纵向状态只能改变排版、间距和可见区域，不能覆盖颜色 Token。

## 6. 核心组件规范

### 6.1 顶部结构

- 标题栏保留产品标题和设置图标，设置使用无文字图标按钮与 Tooltip。
- `今日待办 / 周期任务` 使用悬浮分段控制器。
- 分段控件外层使用 `--ui-control`，选中项使用白色表面和轻微阴影。
- 不再使用角色色下划线或大面积实色导航背景。

### 6.2 今日待办

- 待处理、已完成、全部使用一行紧凑摘要，不拆成三张大卡片。
- 内部筛选复用同一分段控件组件，但尺寸更紧凑。
- 快速新增由输入框和蓝色图标按钮组成；输入内容较长时不改变按钮尺寸。
- 待办卡片使用白色中性表面，选中时使用 `--ui-accent-soft`，不使用角色色左侧竖条。
- 来源与状态标签默认使用灰色，仅异常和完成状态使用语义颜色。

### 6.3 周期任务与详情

- 周期计划卡与待办卡共享边框、圆角、文字层级和交互状态。
- 点击计划后，宽屏进入主从布局，窄屏进入同面板详情页。
- 详情内容块使用中性分组和细分隔线，未知 JSON 块继续使用通用展示组件。
- `AI 生成周期任务` 保持蓝色主按钮；永久删除继续使用危险色并二次确认。

### 6.4 AI 页面与设置

- AI 对话、提案、成功和失败页全部使用相同中性材质。
- 用户消息可使用淡蓝背景，模型消息使用白色表面，不使用角色主题色。
- 设置页中的角色选择器只展示缩略图、名称和选中状态。
- 透明度设置和角色选择互相独立，不出现“角色主题色”选项。

## 7. 角色包协议解耦

`CharacterPackManifestV2` 只描述角色身份、图集和动作：

```ts
interface CharacterPackManifestV2 {
  schemaVersion: 2;
  id: string;
  displayName: string;
  version: string;
  atlas: CharacterAtlas;
  clips: CharacterClips;
}
```

角色包不再包含 `theme`。标准动作继续为：

- 闲置
- 唤醒
- 向下、向上、向左、向右行走
- 工作中
- 完成

向左仍可复用向右图像并镜像。角色生成脚本删除强调色和面板底色参数，只输出图集、Manifest、缩略图和预览材料。

## 8. 兼容与迁移

- 注册表同时接受 `CharacterPackManifestV1` 和 `V2`。
- V1 通过兼容适配器移除 `theme` 后规范化为 V2，运行时组件只接收 V2。
- 默认企鹅资源迁移为 V2，角色 ID 保持 `penguin-todo`，用户选择不会丢失。
- 外观设置升级为 schema v3，继续保存 `characterId` 和 `panelOpacity`。
- 旧值恰好为历史默认 `78%` 时迁移到新默认 `86%`；其他用户自定义透明度保持不变。
- 找不到已选角色时回退到默认企鹅，但不修改待办或计划数据。

## 9. 模块边界

- `styles/neutral-glass-tokens.css`：固定颜色、材质、圆角和阴影 Token。
- `styles/responsive-panel.css`：只管理容器断点和主从布局，不定义颜色。
- `CharacterPack`：只定义角色资产合同。
- `CharacterPackAdapter`：负责 V1 至 V2 规范化。
- `CharacterRegistry`：发现、校验和回退角色。
- `PetSprite`：播放角色动作，不读界面 Token。
- `AppearanceSettings`：保存角色选择和透明度，不管理角色主题。
- 业务组件继续按待办、周期任务、AI 和设置模块拆分。

## 10. 动效与可访问性

- 分段切换使用 `140ms` 颜色和阴影过渡，不移动文字。
- 卡片悬停只改变背景和边框，不整体放大。
- 主从详情进入使用 `180ms` 透明度和轻微位移。
- 按钮按下保持 `0.98` 缩放，减少动效模式下取消缩放和位移。
- 键盘焦点统一使用 `2px` 淡蓝焦点环。
- 所有正文和控件必须在最小 `72%` 面板透明度下保持可读。

## 12. 验收与测试

- 白色文档、蓝色照片和深色壁纸背景下，面板综合色相均保持中性冷白。
- 同一组件在宽屏和窄屏下计算得到相同颜色 Token。
- 更换角色后，界面颜色、圆角、阴影和排版不发生变化。
- V1 和 V2 角色包均可加载，非法 Manifest 能安全回退。
- `360px`、`854px` 和 `960px` 面板无文字溢出、按钮重叠或横向滚动。
- 宽屏详情正确使用 `40/60` 主从布局，两栏可独立滚动。
- 透明度设置重启后恢复，旧设置按规则迁移。
- 执行 `npm test`、`npm run typecheck`、`npm run build` 和单文件 220 行检查。
- 使用 Playwright 或 Electron 截图对三种背景、宽窄面板和角色切换进行视觉验收。
