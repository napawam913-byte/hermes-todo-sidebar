# 今日待办详情抽屉设计

## 目标

今日待办条目支持点击查看详情，并复用周期任务已采用的固定双栏形式。左侧保持 `360px`，右侧详情保持 `400px`，Electron 窗口继续由统一的 `detailOpen` 状态扩为 `760px`。

## 交互

- 点击今日待办卡片主体打开右侧详情。
- 完成和更多操作按钮保持独立，不触发详情。
- 当前选中卡片使用浅青背景和完整轮廓。
- 点击右侧关闭按钮、切换顶部页面或桌面窗口失焦时关闭详情。
- 切换另一条今日待办时复用同一个详情面板，不改变左栏宽度。

## 详情内容

- 手动待办：标题、来源、完成状态、同步状态、备注和可选计划内容块。
- 周期任务：标题、来源计划、主题、日期、完成状态、内容摘要和全部 `contentBlocks`。
- 没有备注或内容块时显示简洁空状态，不伪造字段。

## 组件边界

- `DetailDrawerShell`：只负责右栏壳层、标题、关闭和滚动。
- `CyclePlanDrawer`：继续负责计划条目切换和周期内容。
- `TodayTodoDetailDrawer`：只负责今日条目的领域回显。
- `TodayTodoCard`：只负责列表摘要、完成动作和打开详情。
- `TodayTodoView`：持有当前选中条目，并上报 `detailOpen`。

## 验收

- 周期任务与今日待办都使用同一个 `DetailDrawerShell`。
- 今日待办卡片具有明确的“查看详情”可访问名称。
- 打开今日详情后尺寸为 `360px + 400px`，顶部导航不伸长。
- 周期来源能显示健身动作等内容块，手动来源能显示备注与同步状态。
- 所有 TS、TSX、CSS 文件不超过 220 行。
- `npm test`、`npm run typecheck`、`npm run build` 通过。
