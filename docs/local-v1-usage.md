# 本地正式版使用说明

## 安装与启动

1. 在 `release/` 中运行名称包含 `nsis` 的安装程序，或直接运行包含 `portable` 的便携版。
2. 正式安装版会创建桌面和开始菜单快捷方式。
3. Windows 登录后应用自动启动，默认只显示桌宠入口。
4. 点击桌宠入口或托盘中的“打开待办”展开面板。
5. 收起状态可按住桌宠自由拖动；松手后位置会在下次启动时恢复。

开发模式不会修改 Windows 开机启动项。

## 日常使用

- `今日待办`：新增普通待办、完成待办、查看今日与逾期任务。
- `周期任务`：点击“AI 生成周期任务”，用自然语言描述目标、周期和每天内容；确认标准 JSON 提案后才写入本地数据。
- 周期条目：日期命中当天时自动出现在今日待办；未完成且日期早于今天时显示为逾期。
- 调整计划：打开计划详情后点击“AI 调整”，应用会带入当前计划，补充要求并提交后生成新的变更提案。
- 详情页：待办、周期计划和 AI 流程都在原面板内切换，使用“返回”回到列表。
- 锚定展开：桌宠靠近屏幕上方时面板向下展开，靠近底部时向上展开。
- 外观：界面固定使用冷白 Neutral Glass，透明度范围为 `72%–94%`、默认 `86%`；更换角色只改变桌宠图像与动作。
- 响应式详情：宽度达到 `720px` 时列表与详情按 `40% / 60%` 并列，窄面板继续在同一界面内切页。

第一版没有具体时间和系统通知，不会在某个时刻自动弹窗。

## 模型接口配置

- Base URL 和模型名输入后会自动保存为非敏感草稿；切到浏览器、收起桌宠或切换页面不会丢失。
- 未保存的 API Key 只保留在当前应用内存，应用重启后需要重新输入。
- “测试连接”使用当前表单，不会覆盖正式配置。
- 保存已有配置时 API Key 留空表示继续使用原加密密钥。
- 保存成功后草稿会清除，并进入 AI 对话页。

## 关闭与退出

- 收起或关闭窗口：应用继续驻留系统托盘，数据不会丢失。
- 托盘“隐藏”：隐藏桌宠窗口，但进程仍运行。
- 托盘“退出”：完全结束应用。
- 重复启动：新进程会退出，并唤起已经运行的桌宠。

## 数据来源、备份与导出

正式数据边界：

正式数据由 Plan API/SQLite 管理，不使用本机 JSON 目录作为权威副本。

本机辅助配置：

- `state.v1.json`：首次迁移来源、兼容导出和历史备份，不是正式数据快照。
- `backups/`：旧 JSON 兼容备份，不是 Plan API/SQLite 的正式备份。
- `pet-position.v1.json`：桌宠显示器 ID、`x/y` 和更新时间，不包含待办内容。
- `ai-model-config.v1.json`：正式模型配置，其中 API Key 由 Windows `safeStorage` 加密。
- `ai-config-draft.v1.json`：未完成配置的 Base URL 和模型名，不包含 API Key。

正式备份和恢复请遵循 `docs/desktop-plan-api-integration.md` 的 Plan API 运维步骤。

## 导入与导出

- 托盘“导出数据”：只生成兼容 JSON，不能替代 Plan API/SQLite 备份。
- 托盘“导入数据”：选择此前导出的兼容 JSON；导入前会校验版本和顶层字段。
- 无效导入不会覆盖当前数据。
- 导入成功后界面自动重载。

正式数据恢复使用 Plan API 备份；兼容 JSON 仅适合迁移和导出场景。

## 浏览器预览说明

`http://127.0.0.1:5178` 只用于前端开发预览，使用示例数据和浏览器 `localStorage` Demo。它与正式 Plan API/SQLite 数据相互独立，不能作为正式数据备份。

## 测试便携版说明

- 文件名包含 `-test.` 的便携版使用 `%APPDATA%\hermes-todo-sidebar-test`。
- 测试副本不会写入正式版 `userData`，可以和当前稳定版并存验收。
- `0.1.3-test.14` 使用独立免安装目录；测试通过前保留 `0.1.2` 稳定版和 `0.1.3-test.13` 测试副本，不覆盖也不删除。
