# 本地正式版使用说明

## 安装与启动

1. 在 `release/` 中运行名称包含 `nsis` 的安装程序，或直接运行包含 `portable` 的便携版。
2. 正式安装版会创建桌面和开始菜单快捷方式。
3. Windows 登录后应用自动启动，默认只显示桌宠入口。
4. 点击桌宠入口或托盘中的“打开待办”展开面板。

开发模式不会修改 Windows 开机启动项。

## 日常使用

- `今日待办`：新增普通待办、完成待办、查看今日与逾期任务。
- `周期任务`：点击“手动添加”，填写计划标题、主题、说明和一个或多个日期条目。
- 周期条目：日期命中当天时自动出现在今日待办；未完成且日期早于今天时显示为逾期。
- 编辑计划：打开计划详情后点击“编辑计划”。专业 JSON 内容块会保留，普通详情保存为 Markdown。

第一版没有具体时间和系统通知，不会在某个时刻自动弹窗。

## 关闭与退出

- 收起或关闭窗口：应用继续驻留系统托盘，数据不会丢失。
- 托盘“隐藏”：隐藏桌宠窗口，但进程仍运行。
- 托盘“退出”：完全结束应用。
- 重复启动：新进程会退出，并唤起已经运行的桌宠。

## 数据位置与备份

正式数据目录：

```text
%APPDATA%\hermes-todo-sidebar\data
```

主要文件：

- `state.v1.json`：当前待办、周期计划和设置。
- `backups/`：每次有效修改前保存的备份，只保留最近 7 份。

正式文件损坏时，应用会按时间倒序尝试有效备份。

## 导入与导出

- 托盘“导出数据”：保存完整 JSON 副本。
- 托盘“导入数据”：选择此前导出的 JSON；导入前会校验版本和顶层字段。
- 无效导入不会覆盖当前数据。
- 导入成功后界面自动重载。

建议在更换电脑或进行大量计划调整前导出一次数据。

## 浏览器预览说明

`http://127.0.0.1:5178` 只用于前端开发预览，使用示例数据和浏览器 `localStorage`。它与正式 Electron 的 JSON 文件相互独立，不能作为正式数据备份。
