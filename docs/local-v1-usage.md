# 本地正式版使用说明

## 安装与启动

1. 在 `release/` 中运行名称包含 `nsis` 的安装程序，或直接运行包含 `portable` 的便携版。
2. 正式安装版会创建桌面和开始菜单快捷方式。
3. Windows 登录后应用自动启动，默认只显示桌宠入口。
4. 点击桌宠入口或托盘中的“打开待办”展开面板。
5. 收起状态可按住桌宠自由拖动；松手后位置会在下次启动时恢复。

开发模式不会修改 Windows 开机启动项。

## 日常使用

- `今日待办`：新增普通待办、完成待办、查看今日与逾期任务。
- `周期任务`：点击“手动添加”，填写计划标题、主题、说明和一个或多个日期条目。
- 周期条目：日期命中当天时自动出现在今日待办；未完成且日期早于今天时显示为逾期。
- 编辑计划：打开计划详情后点击“编辑计划”。专业 JSON 内容块会保留，普通详情保存为 Markdown。
- 详情页：待办、周期计划和计划编辑都在原 `360px` 面板内切换，使用“返回”回到列表。
- 锚定展开：桌宠靠近屏幕上方时面板向下展开，靠近底部时向上展开。

第一版没有具体时间和系统通知，不会在某个时刻自动弹窗。

## 关闭与退出

- 收起或关闭窗口：应用继续驻留系统托盘，数据不会丢失。
- 托盘“隐藏”：隐藏桌宠窗口，但进程仍运行。
- 托盘“退出”：完全结束应用。
- 重复启动：新进程会退出，并唤起已经运行的桌宠。

## 数据来源、备份与导出

桌面正式待办和周期计划数据以 Plan API/SQLite 为准。`state.v1.json` 仅作为首次迁移来源、兼容导出和历史备份，不再是正式数据快照；正式备份和恢复请遵循 `docs/desktop-plan-api-integration.md` 的 Plan API 运维步骤。

本机辅助配置仍与正式计划数据分离：

- `pet-position.v1.json`：桌宠显示器 ID、`x/y` 和更新时间，不包含待办内容。

在桌宠“设置 > 数据服务”中可选择本地直连或云端 SSH；数据服务离线时应用只读显示最近缓存，恢复服务或 SSH 连通性后再刷新并重试写入。

托盘“导出数据”只生成兼容 JSON，不能替代 Plan API/SQLite 备份；导入前会校验版本和顶层字段，无效导入不会覆盖当前数据。

## 浏览器预览说明

`http://127.0.0.1:5178` 只用于前端开发预览，使用示例数据和浏览器 `localStorage` Demo。它与正式 Plan API/SQLite 数据相互独立，不能作为正式数据备份。

## 测试便携版说明

- 文件名包含 `-test.` 的便携版使用 `%APPDATA%\hermes-todo-sidebar-test`。
- 测试副本不会写入正式版 `userData`，可以和当前稳定版并存验收。
- 测试通过前保留 `0.1.1` 稳定便携版，不覆盖也不删除。
