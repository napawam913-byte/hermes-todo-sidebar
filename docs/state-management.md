# 桌宠状态管理

## 状态分层

| 状态类别 | 示例 | 收起后 | 重启后 | 保存位置 |
| --- | --- | --- | --- | --- |
| 正式业务状态 | 待办、周期任务、周期条目 | 保留 | 恢复 | `data/state.v1.json` |
| 安全配置状态 | Base URL、模型名、已确认 API Key | 保留 | 恢复 | `ai-model-config.v1.json` |
| 配置草稿状态 | 未保存的 Base URL、模型名 | 保留 | 恢复 | `ai-config-draft.v1.json` |
| UI 会话状态 | 当前页面、设置分区、筛选、详情、编辑表单 | 保留 | 清除 | renderer 内存 |
| AI 会话状态 | 对话、追问、提案、执行结果 | 保留 | 清除 | renderer 与主进程内存 |
| 用户偏好 | 透明度、桌宠位置、开机启动 | 保留 | 恢复 | 独立偏好文件或系统配置 |
| 瞬时交互 | 菜单、删除确认、拖动、动画 | 清除 | 清除 | 组件内存 |

未保存的 API Key 只存在于 renderer 当前应用会话的内存中。它不会写入草稿、`localStorage`、日志、备份或模型上下文。

## 页面会话

`PanelSessionState` 是展开面板唯一的页面状态来源，包含当前工作页、`appearance / model` 设置分区、设置页返回目标和瞬时交互重置版本。顶部 `今日待办 / 周期任务` 由该状态派生，不再分别维护多个布尔值。

设置页宽屏使用左侧导航，紧凑面板使用顶部双 Tab；两种布局读取同一个 `settingsSection`。收起、失焦和切换业务页不会重置分区，点击“完成”返回打开设置前的业务页面。

今日待办、周期任务、AI Flow 和设置页保持挂载，只切换可见性。因此收起桌宠、窗口失焦或切换顶部页面不会销毁快速新增内容、详情选择、API 配置输入和 AI 会话。

收起事件只增加 `interactionResetVersion`，由子模块清除操作菜单和危险确认。待办详情、计划详情、编辑草稿和 AI 请求继续保留。

## API 配置草稿

非敏感草稿格式：

```json
{
  "schemaVersion": 1,
  "baseUrl": "https://api.example.com/v1",
  "model": "model-name",
  "updatedAt": "2026-07-17T00:00:00.000Z"
}
```

Base URL 或模型名变化后约 300ms 防抖保存。测试连接读取当前表单，不修改正式配置。保存已有配置时 API Key 留空会沿用已加密密钥；保存成功后清除草稿文件和 renderer 中的明文输入。

草稿写入按顺序执行，测试和正式保存期间配置输入会暂时锁定。字段变化会使旧连接结果和旧保存结果失效，避免异步响应覆盖较新的输入。

尚未完成首次绑定但存在草稿时，应用重启后的第一次展开会进入配置页；API Key 必须重新输入。已完成绑定时默认进入今日待办。

## AI 上下文

同一周期任务再次进入 AI 调整时恢复现有对话与提案，并刷新计划标题和摘要。切换到另一个计划且存在未确认提案时，必须选择“继续原提案”或“放弃并切换”。应用退出后，未执行提案和聊天记录全部清除。
